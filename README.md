# 💙 Love Site

Анимированное сердце из слов "Love You" с музыкой. Работает в браузере на телефоне и компьютере.

## Установка

sudo bash <(curl -sL https://raw.githubusercontent.com/kurl1k/love-site/main/install.sh) 64321

Или с другим портом:

sudo bash <(curl -sL https://raw.githubusercontent.com/kurl1k/love-site/main/install.sh) 8080

## Что внутри

- index.html — вся страница (анимация + звук через Howler.js)
- love_you.mp3 — музыка
- install.sh — автоустановка на nginx

## Особенности

- Один тап по экрану запускает музыку и анимацию
- Работает на iOS и Android
- Адаптивная вёрстка под любые экраны
- Подпись "by iulik"
